# 🌌 Interstellar: Gargantua

An immersive, interactive space experience inspired by *Interstellar* and the fascinating physics of black holes.

## ✨ Features

- Cinematic introductory screen
- Interactive black-hole experience
- Time dilation information inspired by the film
- Wormhole exploration interaction
- Sound controls
- Responsive layout for desktop and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Google Fonts

## 🚀 Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.
3. Click **Enter** and explore.
